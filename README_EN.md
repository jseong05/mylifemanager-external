## Project overview

My Life Manager External is an experimental Android companion to [My Life Manager](https://github.com/jseong05/mylifemanager), adding AI financial chat, home-screen widgets, and data backup to the original expense and schedule tools. Its application ID, `com.mlm.external`, allows it to be installed alongside the original app.

## Key features

- AI-powered spending and saving coaching
- Expense and schedule management
- Weather, balance, and recommended spending insights
- Home-screen widgets and reminders
- JSON backup/restore and multi-currency support

## Tech stack

- Java, Android
- SharedPreferences, Gson
- Material CalendarView
- OpenWeatherMap API, Groq API
- AlarmManager, BroadcastReceiver, NotificationManager

## Project description

An experimental project that extends a life-management app with AI-powered financial guidance and unified tracking for spending, schedules, and personal goals.
