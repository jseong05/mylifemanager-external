# 📱 My Life Manager External

> **Track your plans and spending, then build better money habits with AI.** My Life Manager External is an experimental Android app that extends a personal finance tracker and planner with AI-powered financial chat, home-screen widgets, and data backup.

[한국어](README.md) · [Original app repository](https://github.com/jseong05/mylifemanager) · [External repository](https://github.com/jseong05/mylifemanager-external)

## ✨ About the project

This repository is an experimental companion version of [My Life Manager](https://github.com/jseong05/mylifemanager). It keeps the original app's core expense tracking, schedule planning, and weather features while exploring AI-assisted money management and other personalized tools. Its application ID is `com.mlm.external`, so it can be installed alongside the original app.

## 🆕 What’s new compared with the original

| Area | Additions and changes in External |
| --- | --- |
| AI financial assistant | AI chat using Groq’s OpenAI-compatible Chat Completions API and the `llama-3.3-70b-versatile` model, saved conversation history, and three response personas |
| Offline responses | Falls back to local rule-based replies when the API key is missing or a network/API request fails |
| Dashboard | Savings-goal progress and a shortcut to AI chat |
| Home-screen widgets | Balance, today’s spending, and recommended daily spending widget; today’s schedule preview widget |
| Expense tracking | Expense categories, expense/income/waste filters, and category spending statistics |
| Backup and restore | Export and restore app data as JSON |
| Notifications | Adds an 8:00 AM daily morning briefing and an 8:00 PM Sunday report to schedule and expense-reminder notifications |
| Settings | AI persona and currency display selection (KRW, USD, JPY, EUR) |
| App identity | Uses the `com.mlm.external` package/application ID to allow side-by-side installation with the original app |

### Latest change

On November 13, 2026, the online AI integration was switched from Gemini to Groq. `AiClient` now uses Groq’s OpenAI-compatible Chat Completions API with the `llama-3.3-70b-versatile` model. If the API is unavailable, the app falls back to local rule-based replies from `OfflineAiEngine`.

## 🌟 Features

### 🏠 Dashboard
- Shows your name, date, current balance, and today’s spending
- Calculates days until your allowance and a recommended daily spending amount
- Summarizes today’s schedule and recent expense entries
- Displays weather based on GPS or a selected city
- Shows savings-goal progress and provides a shortcut to AI chat

### 💰 Expense tracking
- Add, edit, and swipe to delete income and expense entries
- Search by memo and category
- Filter expenses, income, and waste-marked expenses
- Assign food, transport, shopping, culture, or other categories and view category spending statistics
- Mark wasteful spending and review its monthly count and total
- Calculates the current balance from the initial balance and recorded entries

### 📅 Planner and notifications
- Browse schedules in a calendar, with marked dates for scheduled events
- Add, edit, complete, search, and swipe to delete schedules
- Set schedules to repeat never, weekly, monthly, or yearly
- Receive reminders at the scheduled time or a custom interval beforehand
- Daily 8:00 AM morning briefing, Sunday 8:00 PM report, and daily 9:00 PM expense reminder

### 🤖 AI financial assistant
- Ask money-related questions with your current balance and today’s spending as context
- Choose a response persona: Straight-Talking Coach, Kind Counselor, or Pragmatic Financial Officer
- Keeps chat history on the device
- Uses local rule-based replies when the Groq API is unavailable

> Offline replies are generated by the app’s local keyword- and persona-based rules; they do not call an external generative AI model.

### 📱 Home-screen widgets
- **Balance widget:** current balance, today’s spending, recommended daily spending, and days until allowance
- **Schedule widget:** a preview of today’s schedule

### ⚙️ Settings and data management
- Configure your name, initial balance, allowance amount, and allowance cycle
- Set a savings goal and currency display (KRW, USD, JPY, EUR)
- Configure GPS use and the city used for weather
- Export or restore a JSON backup, or reset app data

## 🚀 Build and run

1. Open the project in Android Studio.
2. Sync the Gradle project.
3. If you want to use API-backed features, configure keys in the project-root `local.properties` file.
4. Run the `app` module on an Android 7.0 (API 24) or later emulator or device.

Build from the command line and run local unit tests:

```bash
./gradlew assembleDebug
./gradlew test
```

## 🔑 API key configuration

API keys can be used for weather lookup and online AI chat. Add the following entries to the project-root `local.properties` file:

```properties
weatherApiKey=YOUR_OPENWEATHERMAP_API_KEY
aiApiKey=gsk_YOUR_GROQ_API_KEY
```

- Weather lookup uses an OpenWeatherMap API key.
- Online AI replies use a Groq API key. If the key is missing or a request fails, the app uses local fallback replies.
- Never commit API keys to the repository. `local.properties` is listed in `.gitignore`.
- API keys embedded in a client app can be extracted from a distributed APK. For production key protection, consider routing API requests through a server-side proxy.
- GPS-based weather requires location permission. If permission is unavailable or a location cannot be retrieved, the app uses the configured city.
